# Tescil fişinden alıntı

Faaliyet sınıfı Yatırım olan kuruluş «Mercan Yatırım A.Ş.» adıyla tescillidir.

Vergi idaresi 1255916741 sayılı kimliği Mercan Yatırım adına düzenlemiştir. Aynı şirketin merkez adresi Erzurum ili sınırları içindedir.

Mercan Yatırım nezdindeki hisselerden Irmak Cam adına kayıtlı olanların sermayeye oranı % 58.

Sermayenin % 16 oranındaki dilimi, Mercan Yatırım ortaklık defterinde Doğu Gıda A.Ş. adına tescil edilmiştir.
