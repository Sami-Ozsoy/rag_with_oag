# Tescil fişinden alıntı

Faaliyet sınıfı Danışmanlık olan kuruluş «Zirve Danışmanlık Ltd. Şti.» adıyla tescillidir.

Merkezi Adana ilinde bulunan Zirve Danışmanlık Ltd Şti adına vergi sicilinde 9918489611 kimliği açılmıştır.

Irmak Holding, Zirve Danışmanlık Ltd Şti sermayesine %65 oranıyla iştirak eder.
