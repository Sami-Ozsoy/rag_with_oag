# Tescil fişinden alıntı

Faaliyet sınıfı Sağlık olan kuruluş «Anadolu Sağlık A.Ş.» adıyla tescillidir.

Vergi idaresi 2706550709 sayılı kimliği Anadolu Sağlık A.Ş. adına düzenlemiştir. Aynı şirketin merkez adresi Ordu ili sınırları içindedir.

Sermayenin % 57 oranındaki dilimi, Anadolu Sağlık A.Ş. ortaklık defterinde Toros Gıda A.Ş. adına tescil edilmiştir.
