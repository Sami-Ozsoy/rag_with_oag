# Tescil fişinden alıntı

Faaliyet sınıfı Elektronik olan kuruluş «Koru Elektronik A.Ş.» adıyla tescillidir.

Koru Elektronik AŞ — Merkez ili Çanakkale / Vergi mükellefi kimliği 7757520966.

Sermayenin 73% oranındaki dilimi, Koru Elektronik AŞ ortaklık defterinde Kozalak Mobilya AŞ adına tescil edilmiştir.
