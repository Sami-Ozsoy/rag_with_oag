# Tescil fişinden alıntı

Faaliyet sınıfı Gıda olan kuruluş «Çamlı Gıda Ltd. Şti.» adıyla tescillidir.

Merkezi İzmir ilinde bulunan Çamlı Gıda adına vergi sicilinde 5481685942 kimliği açılmıştır.

Sermayenin % 59 oranındaki dilimi, Çamlı Gıda ortaklık defterinde Işık Ambalaj Dış Ticaret Ltd. Şti. adına tescil edilmiştir.
