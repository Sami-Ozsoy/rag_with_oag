# Tescil fişinden alıntı

Faaliyet sınıfı Sağlık olan kuruluş «Defne Sağlık Ltd. Şti.» adıyla tescillidir.

Merkezi Edirne ilinde bulunan Defne Sağlık Ltd Şti adına vergi sicilinde 4881835131 kimliği açılmıştır.

Defne Sağlık Ltd Şti nezdindeki hisselerden Rüzgâr Holding AŞ adına kayıtlı olanların sermayeye oranı 56%.
