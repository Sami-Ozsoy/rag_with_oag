# Tescil fişinden alıntı

Faaliyet sınıfı İnşaat olan kuruluş «Koru İnşaat A.Ş.» adıyla tescillidir.

Vergi idaresi 8565692363 sayılı kimliği Koru İnşaat A.Ş. adına düzenlemiştir. Aynı şirketin merkez adresi Edirne ili sınırları içindedir.

Sermayenin % 56 oranındaki dilimi, Koru İnşaat A.Ş. ortaklık defterinde Bulut Mobilya Pazarlama A.Ş. adına tescil edilmiştir.
