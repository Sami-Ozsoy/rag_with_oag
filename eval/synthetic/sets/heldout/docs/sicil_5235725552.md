# Tescil fişinden alıntı

Faaliyet sınıfı Yazılım olan kuruluş «Turna Yazılım Ltd. Şti.» adıyla tescillidir.

Vergi idaresi 5235725552 sayılı kimliği Turna Yazılım Ltd. Şti. adına düzenlemiştir. Aynı şirketin merkez adresi Samsun ili sınırları içindedir.

Ayaz Elektronik A.Ş., Turna Yazılım Ltd. Şti. sermayesine 64% oranıyla iştirak eder.
