# Tescil fişinden alıntı

Faaliyet sınıfı Tekstil olan kuruluş «Kaya Tekstil A.Ş.» adıyla tescillidir.

Merkezi Çanakkale ilinde bulunan Kaya Tekstil AŞ adına vergi sicilinde 4368167113 kimliği açılmıştır.

Kaya Tekstil AŞ sermayesinin ortaklara göre dağılımı aşağıda verilmiştir.

- Lale Holding A.Ş. — sermaye payı % 70
- Simge Yatırım — sermaye payı 9%
