# Tescil fişinden alıntı

Faaliyet sınıfı Mobilya olan kuruluş «Belen Mobilya Dış Ticaret Ltd. Şti.» adıyla tescillidir.

Merkezi Balıkesir ilinde bulunan Belen Mobilya Dış Ticaret Ltd. Şti. adına vergi sicilinde 1934430823 kimliği açılmıştır.

Pınar Mobilya Ltd. Şti., Belen Mobilya Dış Ticaret Ltd. Şti. sermayesine 18% oranıyla iştirak eder.
