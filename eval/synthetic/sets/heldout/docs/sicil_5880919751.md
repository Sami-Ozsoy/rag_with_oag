# Tescil fişinden alıntı

Faaliyet sınıfı Elektronik olan kuruluş «Gelincik Elektronik A.Ş.» adıyla tescillidir.

Gelincik Elektronik — Merkez ili Erzurum / Vergi mükellefi kimliği 5880919751.

Sermayenin yüzde 18 oranındaki dilimi, Gelincik Elektronik ortaklık defterinde Kaya Yatırım adına tescil edilmiştir.
