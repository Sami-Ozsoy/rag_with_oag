# Tescil fişinden alıntı

Faaliyet sınıfı Yapı olan kuruluş «Anadolu Yapı Ltd. Şti.» adıyla tescillidir.

Vergi idaresi 7789903628 sayılı kimliği Anadolu Yapı Ltd. Şti. adına düzenlemiştir. Aynı şirketin merkez adresi Malatya ili sınırları içindedir.

Sermayenin %78 oranındaki dilimi, Anadolu Yapı Ltd. Şti. ortaklık defterinde Kaya Yatırım A.Ş. adına tescil edilmiştir.
