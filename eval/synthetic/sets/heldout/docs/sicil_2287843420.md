# Tescil fişinden alıntı

Faaliyet sınıfı Mobilya olan kuruluş «Bozdağ Mobilya Yatırım Grubu Ltd. Şti.» adıyla tescillidir.

Merkezi Antalya ilinde bulunan Bozdağ Mobilya Yatırım Grubu Ltd. Şti. adına vergi sicilinde 2287843420 kimliği açılmıştır.

Bozdağ Mobilya Yatırım Grubu Ltd. Şti. nezdindeki hisselerden Defne Sağlık Ltd Şti adına kayıtlı olanların sermayeye oranı 61%.
