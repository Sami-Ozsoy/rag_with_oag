# Tescil fişinden alıntı

Faaliyet sınıfı Makine olan kuruluş «Kuzey Makine Ltd. Şti.» adıyla tescillidir.

Merkezi Mersin ilinde bulunan Kuzey Makine Ltd. Şti. adına vergi sicilinde 6889732185 kimliği açılmıştır.

Kuzey Makine Ltd. Şti. sermayesindeki 69% payın sahibi olarak Kuzgun İnşaat Ltd Şti kayda geçmiştir.

Kuzey Makine Ltd. Şti. nezdindeki hisselerden Koru Makine Ltd Şti adına kayıtlı olanların sermayeye oranı % 15.
