# Tescil fişinden alıntı

Faaliyet sınıfı Yapı olan kuruluş «Kozalak Yapı Ltd. Şti.» adıyla tescillidir.

Merkezi Adana ilinde bulunan Kozalak Yapı Ltd. Şti. adına vergi sicilinde 8179661340 kimliği açılmıştır.

Sermayenin 62% oranındaki dilimi, Kozalak Yapı Ltd. Şti. ortaklık defterinde Doğa Lojistik A.Ş. adına tescil edilmiştir.
