# Tescil fişinden alıntı

Faaliyet sınıfı Ambalaj olan kuruluş «Işık Ambalaj Ltd. Şti.» adıyla tescillidir.

Vergi idaresi 3871840003 sayılı kimliği Işık Ambalaj Ltd. Şti. adına düzenlemiştir. Aynı şirketin merkez adresi Tekirdağ ili sınırları içindedir.

Sermayenin % 53 oranındaki dilimi, Işık Ambalaj Ltd. Şti. ortaklık defterinde Kuzgun İnşaat Ltd Şti adına tescil edilmiştir.
