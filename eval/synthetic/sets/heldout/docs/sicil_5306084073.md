# Tescil fişinden alıntı

Faaliyet sınıfı Mobilya olan kuruluş «Meşe Mobilya Ltd. Şti.» adıyla tescillidir.

Vergi idaresi 5306084073 sayılı kimliği Meşe Mobilya Ltd. Şti. adına düzenlemiştir. Aynı şirketin merkez adresi Gaziantep ili sınırları içindedir.

Bozdağ Metal A.Ş., Meşe Mobilya Ltd. Şti. sermayesine yüzde 83 oranıyla iştirak eder.
