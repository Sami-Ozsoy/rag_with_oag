# Etkinlik ajandası 051 | Mahalle sahnesi

Kukla gösterisinde kullanılacak gölgeler akşam provasına yetişti. Program defterine Kuzgun İnşaat Yatırım Grubu Ltd Şti ekibinden gelen seyircilerin giriş kapısı da çizildi. Ara verildiğinde izleyiciler bahçedeki bez afişlerin nasıl boyandığını atölye gönüllülerine sordu.
