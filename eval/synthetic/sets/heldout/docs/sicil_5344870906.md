# Tescil fişinden alıntı

Faaliyet sınıfı Lojistik olan kuruluş «Ayaz Lojistik Ltd. Şti.» adıyla tescillidir.

Vergi idaresi 5344870906 sayılı kimliği Ayaz Lojistik Ltd. Şti. adına düzenlemiştir. Aynı şirketin merkez adresi Denizli ili sınırları içindedir.

Ayaz Lojistik Ltd. Şti. nezdindeki hisselerden Meşe Mobilya Ltd. Şti. adına kayıtlı olanların sermayeye oranı % 72.
