# Etkinlik ajandası 001 | Açık hava çizimleri

İskele başında çizim yapan grup, kâğıtlar rüzgârda kalkmasın diye mandal getirdi. Engin Ambalaj Dış Ticaret Ltd. Şti. ekibinden katılanlar ufuk çizgisini farklı renklerle denedi. Toplanma saati yaklaşınca yarım kalan çalışmaların fotoğrafları ortak albüme yüklendi.
