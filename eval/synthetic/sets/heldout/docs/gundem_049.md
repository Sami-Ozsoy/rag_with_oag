# Etkinlik ajandası 049 | Mahalle sahnesi

Kukla gösterisinde kullanılacak gölgeler akşam provasına yetişti. Program defterine Uludağ Danışmanlık Ltd. Şti. ekibinden gelen seyircilerin giriş kapısı da çizildi. Ara verildiğinde izleyiciler bahçedeki bez afişlerin nasıl boyandığını atölye gönüllülerine sordu.
