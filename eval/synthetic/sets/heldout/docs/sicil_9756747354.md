# Tescil fişinden alıntı

Faaliyet sınıfı Yazılım olan kuruluş «Nil Yazılım Dağıtım A.Ş.» adıyla tescillidir.

Vergi idaresi 9756747354 sayılı kimliği Nil Yazılım Dağıtım AŞ adına düzenlemiştir. Aynı şirketin merkez adresi Çanakkale ili sınırları içindedir.

Nil Yazılım Dağıtım AŞ nezdindeki hisselerden Pınar Mobilya Ltd Şti adına kayıtlı olanların sermayeye oranı 63%.
