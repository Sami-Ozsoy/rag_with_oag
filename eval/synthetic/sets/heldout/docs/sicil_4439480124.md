# Tescil fişinden alıntı

Faaliyet sınıfı Ambalaj olan kuruluş «Milas Ambalaj Dağıtım A.Ş.» adıyla tescillidir.

Vergi idaresi 4439480124 sayılı kimliği Milas Ambalaj Dağıtım A.Ş. adına düzenlemiştir. Aynı şirketin merkez adresi Aydın ili sınırları içindedir.

Sermayenin %81 oranındaki dilimi, Milas Ambalaj Dağıtım A.Ş. ortaklık defterinde Işık Ambalaj Dış Ticaret Ltd. Şti. adına tescil edilmiştir.
