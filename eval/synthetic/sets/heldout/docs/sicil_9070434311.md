# Tescil fişinden alıntı

Faaliyet sınıfı Tekstil olan kuruluş «Karaca Tekstil Pazarlama Ltd. Şti.» adıyla tescillidir.

Merkezi Mersin ilinde bulunan Karaca Tekstil Pazarlama Ltd Şti adına vergi sicilinde 9070434311 kimliği açılmıştır.

Sermayenin yüzde 82 oranındaki dilimi, Karaca Tekstil Pazarlama Ltd Şti ortaklık defterinde Meşe Makine Ltd. Şti. adına tescil edilmiştir.
