# Etkinlik ajandası 011 | Açık hava çizimleri

İskele başında çizim yapan grup, kâğıtlar rüzgârda kalkmasın diye mandal getirdi. Ekin Kimya Yatırım Grubu Ltd. Şti. ekibinden katılanlar ufuk çizgisini farklı renklerle denedi. Toplanma saati yaklaşınca yarım kalan çalışmaların fotoğrafları ortak albüme yüklendi.
