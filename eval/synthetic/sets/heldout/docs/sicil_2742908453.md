# Tescil fişinden alıntı

Faaliyet sınıfı Enerji olan kuruluş «Çamlı Enerji Ltd. Şti.» adıyla tescillidir.

Merkezi Balıkesir ilinde bulunan Çamlı Enerji adına vergi sicilinde 2742908453 kimliği açılmıştır.

Çamlı Enerji nezdindeki hisselerden Yonca Holding AŞ adına kayıtlı olanların sermayeye oranı 55%.
