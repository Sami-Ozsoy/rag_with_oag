# Ticaret Sicil Kaydı

Lale Cam Yatırım Grubu Ltd. Şti. için açılan sicil dosyasında şirket merkezi Denizli, vergi numarası 5299558249 olarak geçer.

Kayıtlı ticaret unvanı “Lale Cam Yatırım Grubu Ltd. Şti.” olarak geçer. Faaliyet alanı Cam.

Lale Cam Yatırım Grubu Ltd. Şti. için ortaklık dökümünde Anadolu Holding A.Ş. (% 82) pay sahibi olarak gösterilmiştir.
