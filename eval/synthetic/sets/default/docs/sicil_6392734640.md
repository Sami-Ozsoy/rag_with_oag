# Ticaret Sicil Kaydı

Hisar Kâğıt A.Ş. için açılan sicil dosyasında şirket merkezi Gaziantep, vergi numarası 6392734640 olarak geçer.

Kayıtlı ticaret unvanı “Hisar Kâğıt A.Ş.” olarak geçer. Faaliyet alanı Kâğıt.

Hisar Kâğıt A.Ş. şirketindeki payların % 82 oranındaki bölümü Kuzey Holding A.Ş. tarafından tutulmaktadır.
