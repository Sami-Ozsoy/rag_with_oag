# Ticaret Sicil Kaydı

Doğa İnşaat Yatırım Grubu A.Ş. için açılan sicil dosyasında şirket merkezi İzmir, vergi numarası 2531516257 olarak geçer.

Kayıtlı ticaret unvanı “Doğa İnşaat Yatırım Grubu A.Ş.” olarak geçer. Faaliyet alanı İnşaat.

Doğa İnşaat Yatırım Grubu A.Ş. için ortaklık dökümünde Kaya Holding (54%) pay sahibi olarak gösterilmiştir.
