# Ticaret Sicil Kaydı

Toprak Gıda A.Ş. için açılan sicil dosyasında şirket merkezi İstanbul, vergi numarası 4432410950 olarak geçer.

Kayıtlı ticaret unvanı “Toprak Gıda A.Ş.” olarak geçer. Faaliyet alanı Gıda.

Toprak Gıda A.Ş. şirketindeki payların % 60 oranındaki bölümü Turna Danışmanlık A.Ş. tarafından tutulmaktadır.
