# Ticaret Sicil Kaydı

Toprak Danışmanlık Ltd Şti için açılan sicil dosyasında şirket merkezi Ordu, vergi numarası 3955820429 olarak geçer.

Kayıtlı ticaret unvanı “Toprak Danışmanlık Ltd. Şti.” olarak geçer. Faaliyet alanı Danışmanlık.

Toprak Danışmanlık Ltd Şti şirketinin ortakları arasında 74% payla Engin Kimya Ltd. Şti. yer almaktadır.

Gelincik Tarım, Toprak Danışmanlık Ltd Şti unvanlı şirketin sermayesinde yüzde 20 oranında paya sahiptir.
