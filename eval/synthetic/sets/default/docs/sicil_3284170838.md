# Ticaret Sicil Kaydı

Toprak Mobilya adına tescil edilen vergi kimlik numarası 3284170838; merkez ili ise Muğla olarak kayıtlıdır.

Kayıtlı ticaret unvanı “Toprak Mobilya Ltd. Şti.” olarak geçer. Faaliyet alanı Mobilya.

Işık Cam AŞ, Toprak Mobilya unvanlı şirketin sermayesinde yüzde 54 oranında paya sahiptir.
