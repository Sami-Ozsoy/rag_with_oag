# Ticaret Sicil Kaydı

İnci Sağlık Pazarlama Ltd. Şti. adına tescil edilen vergi kimlik numarası 1863202764; merkez ili ise İzmir olarak kayıtlıdır.

Kayıtlı ticaret unvanı “İnci Sağlık Pazarlama Ltd. Şti.” olarak geçer. Faaliyet alanı Sağlık.

İnci Sağlık Pazarlama Ltd. Şti. şirketindeki payların %61 oranındaki bölümü Lodos İnşaat A.Ş. tarafından tutulmaktadır.

İnci Sağlık Pazarlama Ltd. Şti. için ortaklık dökümünde Deniz Makine Ltd. Şti. (yüzde 9) pay sahibi olarak gösterilmiştir.
