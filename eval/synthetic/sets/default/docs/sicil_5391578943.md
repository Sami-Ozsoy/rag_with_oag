# Ticaret Sicil Kaydı

Meşe Gıda Dağıtım Ltd Şti için açılan sicil dosyasında şirket merkezi Sakarya, vergi numarası 5391578943 olarak geçer.

Kayıtlı ticaret unvanı “Meşe Gıda Dağıtım Ltd. Şti.” olarak geçer. Faaliyet alanı Gıda.

Meşe Gıda Dağıtım Ltd Şti şirketinin ortakları arasında 53% payla Kemer Holding A.Ş. yer almaktadır.

Meşe Gıda Dağıtım Ltd Şti için ortaklık dökümünde Belen Holding AŞ (%11) pay sahibi olarak gösterilmiştir.
