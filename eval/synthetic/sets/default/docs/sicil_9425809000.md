# Ticaret Sicil Kaydı

Milas Tekstil Dış Ticaret Ltd. Şti. adına tescil edilen vergi kimlik numarası 9425809000; merkez ili ise Trabzon olarak kayıtlıdır.

Kayıtlı ticaret unvanı “Milas Tekstil Dış Ticaret Ltd. Şti.” olarak geçer. Faaliyet alanı Tekstil.

Milas Tekstil Dış Ticaret Ltd. Şti. şirketindeki payların %79 oranındaki bölümü Toros Makine tarafından tutulmaktadır.
