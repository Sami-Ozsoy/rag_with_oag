# Ticaret Sicil Kaydı

Gökçe Danışmanlık Ltd Şti sicil özetinde merkez ili Diyarbakır olarak belirtilmiştir. Vergi no: 6995080702.

Kayıtlı ticaret unvanı “Gökçe Danışmanlık Ltd. Şti.” olarak geçer. Faaliyet alanı Danışmanlık.

Gökçe Danışmanlık Ltd Şti şirketinin ortakları arasında %63 payla Uludağ Holding A.Ş. yer almaktadır.

Dalyan Metal A.Ş., Gökçe Danışmanlık Ltd Şti unvanlı şirketin sermayesinde % 15 oranında paya sahiptir.

Doruk Holding A.Ş., Gökçe Danışmanlık Ltd Şti unvanlı şirketin sermayesinde yüzde 17 oranında paya sahiptir.
