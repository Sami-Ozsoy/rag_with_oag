# Ticaret Sicil Kaydı

Çınar Kâğıt Ltd. Şti. sicil özetinde merkez ili Ankara olarak belirtilmiştir. Vergi no: 1740223519.

Kayıtlı ticaret unvanı “Çınar Kâğıt Ltd. Şti.” olarak geçer. Faaliyet alanı Kâğıt.

Ekin Holding, Çınar Kâğıt Ltd. Şti. unvanlı şirketin sermayesinde % 72 oranında paya sahiptir.

Çınar Kâğıt Ltd. Şti. şirketindeki payların %12 oranındaki bölümü Yıldız Holding A.Ş. tarafından tutulmaktadır.
