# Ticaret Sicil Kaydı

Koru Yazılım AŞ için açılan sicil dosyasında şirket merkezi Samsun, vergi numarası 7974713680 olarak geçer.

Kayıtlı ticaret unvanı “Koru Yazılım A.Ş.” olarak geçer. Faaliyet alanı Yazılım.

Çağlayan Lojistik Ltd Şti, Koru Yazılım AŞ unvanlı şirketin sermayesinde yüzde 62 oranında paya sahiptir.

Koru Yazılım AŞ için ortaklık dökümünde Yeşil Ambalaj AŞ (% 6) pay sahibi olarak gösterilmiştir.
