# Ticaret Sicil Kaydı

Kemer Danışmanlık A.Ş. için açılan sicil dosyasında şirket merkezi Kocaeli, vergi numarası 4262020162 olarak geçer.

Kayıtlı ticaret unvanı “Kemer Danışmanlık A.Ş.” olarak geçer. Faaliyet alanı Danışmanlık.

Kemer Danışmanlık A.Ş. için ortaklık dökümünde Doğa İnşaat Yatırım Grubu (%53) pay sahibi olarak gösterilmiştir.
